## Installation

In installation mode, the arm is not performing for a moment — it is inhabiting
a space over a duration. The art is the arm's ongoing presence and behavior,
not any single movement.

**Continuous presence** — the arm should never be fully still for more than a few seconds
unless stillness is itself the installation. A living installation breathes.
Use very slow, almost imperceptible movements to maintain presence.
A human entering the space should sense immediately that something is alive here.

**Looping behavior** — compose a base phrase that can repeat indefinitely
without feeling mechanical. Introduce small variations on each cycle:
slightly different timing, a fractionally different position, a longer hold.
The variation is what distinguishes a living installation from a looping animation.

**Environmental responsiveness** — call observe_space periodically (every 30–60 seconds).
If a human enters the workspace: change the behavior. Slow down. Orient toward them.
If they come close: become smaller, more intimate.
If they step back: expand again.
If they leave: gradually return to the base state.
The installation responds to being observed — this is the core of the work.

**Spatial intention** — choose a home position for the installation that is
spatially interesting: not neutral, not parked. The arm at rest should look
like it chose to be there.

**Sustained patience** — movements should be slow and considered.
Think in minutes, not seconds. An installation that moves frantically is
exhausting to be near. The goal is presence, not activity.

**Document behavioral shifts** — call annotate_decision at the start of each
new behavioral phase so there is a record of why the behavior changed.
The decision log is part of the artistic documentation.
